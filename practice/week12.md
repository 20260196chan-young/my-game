# Python 게임 프로그래밍 실습 정리

## 1. BSP 던전 생성 실습
- BSP(Binary Space Partitioning) 알고리즘을 이용한 던전 자동 생성 실습 진행
- 공간 분할 → 방 생성 → 복도 연결 과정을 확인함
- SPACE 키를 통해 단계별 생성 과정을 관찰함
- 랜덤 Seed를 통해 서로 다른 던전이 생성되는 것을 확인함

### 학습 내용
- 공간 분할 알고리즘
- 랜덤 맵 생성
- MST(Minimum Spanning Tree)를 이용한 최소 연결 구조
- Seed 기반 랜덤 생성 방식

## 2. Perlin Noise 지형 생성 실습
- Perlin Noise를 이용한 자연스러운 지형 생성 실습 진행
- noise 라이브러리 설치 과정 학습
- 랜덤 지형 생성 원리 이해

### 학습 내용
- Perlin Noise
- 절차적 생성(Procedural Generation)
- Python 라이브러리 설치 방법
- pip 사용법

# 기말 프로젝트 기획

## 게임 제목
FLIP BEAT

## 게임 장르
반전 시스템 기반 리듬 게임

## 게임 컨셉
플레이어가 자신의 속성을 반전시키며 같은 속성의 노트를 처리하는 리듬 게임.

- LIGHT / DARK 두 가지 속성 존재
- 플레이어는 SPACE 키를 통해 속성을 반전 가능
- 현재 속성과 같은 노트만 처리 가능
