# 6주차 실습 기록

## 사용한 에셋
- 이미지: player.png (직접 제작 / AI 생성)
- 사운드:
  - shoot.wav (직접 생성 코드 사용)
  - bgm.wav (직접 생성 코드 사용)

---

## 사용한 AI 프롬프트 (요약)
1. pygame에서 이미지 출력 및 이동 방법 요청
2. 효과음 및 배경음 생성 및 적용 방법 질문
3. 사운드 반복, 페이드인, 클릭 이벤트 적용 방법 질문
4. 스프라이트 및 애니메이션 구현 방법 질문

---

## AI 답변에서 도움이 된 것
- pygame에서 이미지 불러오고 화면에 출력하는 방법 이해
- 효과음과 배경음악을 각각 다르게 사용하는 방법 학습
- sound.play(), music.play() 차이 이해
- 마우스 클릭 이벤트 처리 방법 학습
- fade_in을 이용한 배경음 시작 효과 적용

---

## AI 답변을 수정하거나 버린 것
- numpy를 이용한 사운드 생성 방식 → 설치 문제로 사용 안 함
- 복잡한 스프라이트 시트 방식 → 단일 이미지 방식으로 변경
- 일부 경로 문제 코드 → 현재 폴더 기준으로 수정

---

- 잘 된 것:
